# GitHub Copilot Instructions

## Project Goal
Improve and maintain the Sudoku application while preserving all existing functionality.

## Coding Guidelines
- Keep the existing project structure.
- Write clean, modular, and readable code.
- Follow Python and JavaScript best practices.
- Do not remove working features.
- Add comments where needed.
- Keep all existing tests passing.

## UI Guidelines
- Maintain responsive layout.
- Keep dark mode working.
- Preserve accessibility.
- Alternate colors for the 3x3 Sudoku blocks.
- Invalid moves should immediately provide visual feedback.

## Copilot Guidance
When suggesting code:
- Prefer small reusable functions.
- Avoid unnecessary complexity.
- Preserve existing behavior.
- Suggest code that is easy to test and maintain.
